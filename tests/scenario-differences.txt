# Every difference between a scenario's picture with pymux and one without.
# `tests/photograph_scenarios.py` says what this is and how to write it.
#
# A count is exact unless it is a range, and a range says why it moves.

# ----------------------------------------------------------------------
# claude-code, on one shared stream.
#
# One-pixel seams: at two cell joins in the mascot, at the "●" before
# "high", and at column 79 of the two rules. The last two are the
# mechanism `picture-differences.txt` records for the recorded
# claude-code fixture (#371, #539). The mascot seams are not traced, and
# the count moves between runs with the same text on screen: 35, 17, 24
# and 24 measured. Lillecarl/pymux#601.
xterm claude-code answer 17-35
xterm claude-code start 17-35

# ----------------------------------------------------------------------
# yazi-images: each terminal runs and answers a yazi of its own.

# foot. yazi sends sixel on both sides. Through pymux, the earlier
# previews stay on the screen after yazi moves on; the first two
# images are still alone. Lillecarl/pymux#598.
foot yazi-images forest-portrait 24668
foot yazi-images pug 154626
foot yazi-images puppy-icon 217811
foot yazi-images river-panorama 199401
foot yazi-images walrus-grey 128725

# kitty. pymux tells yazi it is kitty (`pymux/hacks_and_lies.py`), so
# both sides get Unicode placeholders, in the same place. pymux
# resamples the picture to fill its cells, where kitty draws it at its
# own pixel size: everywhere a little, unless yazi had already scaled
# the image to the cells, as for dog and walrus. Lillecarl/pymux#600.
kitty yazi-images dog 4
kitty yazi-images dog-small 15655
kitty yazi-images forest-portrait 140594
kitty yazi-images pug 67556
kitty yazi-images puppy-icon 2742
kitty yazi-images river-panorama 16830
kitty yazi-images walrus-grey 3

# xterm. This xterm offers yazi no image protocol, so the bare side
# shows no preview. pymux offers one, takes yazi's image, and draws it
# in cells of colour: pymux shows more than the terminal it runs in.

xterm yazi-images dog-small 19200
