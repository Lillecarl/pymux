# Every difference between a fixture drawn with `render-mode optimized`
# and with `render-mode reference`, in one terminal. A count is a number
# of pixels. `tests/photograph_chrome.py` reads it when
# PYMUX_CHROME_RENDER_MODE is "both", and fails a fixture whose count is
# not the one here.
#
# Only xterm has any, and each is one grey pixel at the left edge of a
# cell. Measured on which-key: (390, 167) is 53 grey optimized and 28,
# the background, in reference. The glyph to the left inks a pixel past
# its own cell. The optimized writer puts the two cells out in one
# string, and xterm keeps that ink. The reference writer moves to every
# cell and writes it alone, and the cell's background covers the ink.
# This is the seam of Lillecarl/pymux#371 again. kitty and foot show
# no difference on any fixture.
#
# A missing or misplaced cell is a whole cell of pixels, not one.
xterm compose-a-key 1
xterm copy-mode 18
xterm pane-text 18
xterm switch-panes-full 18
xterm which-key 40
